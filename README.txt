Aplicativo Android voltado para o estudo e navegação da infraestrutura geográfica dos Estados Unidos (estados, condados, cidades, rodovias, ferrovias, aeroportos, portos, rios e lagos).
Este aplicativo é um projeto independente e está em fase de testes (versão beta). Se você encontrar algum problema ou tiver sugestões, por favor abra uma issue em

https://github.com/Bellece/GeoUSA/issues

Você pode baixar a versão mais recente do aplicativo diretamente em nossa página de lançamentos:

https://github.com/Bellece/GeoUSA/releases/latest

Como instalar:
1. Baixe o arquivo ‘.apk’ no celular.
2. Abra o arquivo baixado. Se solicitado, permita a instalação a partir desta fonte nas configurações do Android.
3. Conclua a instalação e abra o app.
Este aplicativo é disponibilizado de forma **100% gratuita**.
Acesso à Internet: Apenas ao Google Maps.

Tecnologias Utilizadas
Linguagem: Kotlin
UI: Jetpack Compose
Banco de Dados: Room / SQLite – O banco é local, embutido no aplicativo.
